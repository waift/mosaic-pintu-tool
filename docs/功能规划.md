## 二、功能清单

> ⚠️ 所有新功能都受**离线单文件**形态约束：不能依赖后端 API，不能引外部 CDN 资源。

### P0 — 价值最高，当前完全空白

#### 1. 单张图片编辑

| 子项 | 说明 |
|---|---|
| 旋转 / 翻转 | 90° / 180° / 270° / 任意角度；水平、垂直镜像 |
| 裁剪 | 自由裁剪 + 固定比例（1:1 / 4:3 / 9:16） |
| 调色 | 亮度 / 对比度 / 饱和度 |
| 滤镜预设 | 复古 / 黑白 / 清新 |

**前置条件**：先解决决策 #1（画布库）。直接在现有 `utils/image.ts` 上堆会让它彻底失控。

**建议前置**：补组件层测试（开发报告 D2）。这是体量最大的一块改动，没有回归保护风险高。

---

### P1 — 高价值迭代

#### 2. 撤销 / 重做

- 基于 zustand + `zundo` 中间件做历史栈
- 覆盖：删除、排序、改配置、（未来的）编辑操作
- 快捷键 `Ctrl+Z` / `Ctrl+Shift+Z` + 界面按钮
- **配套**：需要先拆 store slice（开发报告 D4）
- **契合点**：`stitchStore` 的 `removeImage` / `removeImages` / `reorderImages` / `setImages` 天然适合进历史栈

#### 3. 网格 / 模板拼图

- 预设布局：九宫格、品字、田字、海报、心形
- 需要「裁剪填充」（crop to uniform）把不同尺寸的图统一
- 这一项能让「拼图」这个名字名副其实——当前实质只做长图拼接

#### 4. 下载增强

- 自定义文件名
- 导出 PDF
- 按目标体积自动调质量（如控制在 2MB 内）

#### 5. 实时预览

- 拖动配置时右侧实时重算，免去每次点「生成」
- **注意**：会加剧主线程卡顿，建议与 Web Worker（开发报告 D5）一起做

### P2 — 增强 / 探索

| # | 功能 | 说明 |
|---|---|---|
| 6 | 水印 | 文字（位置 / 透明度 / 旋转）+ logo 图片 |

| 12 | AI 辅助（抠图 / 智能构图） | ⚠️ 需 wasm 模型或联网，**离线单文件版（`file://`）受限**，可能只能在网站版提供 |

## 三、建议推进顺序

1. **补组件层测试**（开发报告 D2）—— 给后面的大改动兜底
2. **撤销重做**（P1 #2）—— 体量适中，直接提升容错，顺带完成 store 拆分
3. **拍板画布库**（决策 #1）→ **单图编辑**（P0 #1）
4. **网格模板**（P1 #3）
5. 滚动推进 P2

> 也可以先做 **Prettier**（开发报告 D1），十分钟的事，一劳永逸。

## 附：已否决方案

> 记录在案，**避免将来反复讨论同一件事**。

### ❌ 多选拖拽：方案 C —— 选中项收缩为 12px 虚线细槽

- **提出时间**：2026-08-08
- **做法**：整组拖动时，被选中的图从 80px 宽动画收缩成 12px 虚线细槽，队列视觉上合拢但槽位仍在（不触发 flex-wrap 换行重排）。
- **完成度**：**已完整实现并通过 Playwright 4 场景验证**（收缩宽度、合拢后碰撞检测、拖到末尾、单张不触发收缩）。
- **否决原因**：用户实测后认为体验不佳。
- **处理**：`git reset --hard` 丢弃提交 `4a19e42`，未进入主干。
- **结论**：**保持现有的虚线占位镜像方案**（开发报告 ADR-4）。后续**不再提案**"收缩细槽"或"完全抽出"类方案。

### ❌ 多选拖拽：方案 B —— 原地完全不留镜像

- **做法**：拖动时选中项彻底从队列移除，后方图片 FLIP 动画合拢，落点用插入光标提示。
- **否决原因**：评估阶段即否决。本项目弹窗是 `flex-wrap` **多行布局**，抽走多张会引发**换行重排**——第二行的图被吸到第一行末尾，大面积位移，视觉冲击强。且需额外实现 FLIP 动画、插入光标、自定义 dropAnimation，约 100–150 行，风险收益不匹配。
- **结论**：同上，不再提案。

### ❌ 单击上传区自动读取剪贴板

- **原实现**：单击调用 `navigator.clipboard.read()` 自动识别剪贴板图片。
- **否决原因**：触发权限弹窗、剪贴板为空时弹无意义 toast。
- **替代方案**：改为单击高亮"待粘贴"态（开发报告 ADR-5），已于 `620afd2` 上线。
