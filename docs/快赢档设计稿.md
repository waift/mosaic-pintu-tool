## 0. 设计策略

- **落点优先**：5 项（F1–F5）全部复用现有布局骨架与组件，不做新页面。改动集中在 header / 左栏 StitchConfig+ImageList / 右栏 PreviewPanel 下载条 / 新增 footer。
- **双主题**：所有控件走 `design规范.md` 的 token 变量（base/ink/accent/warn 双主题值），不写死十六进制。设计稿以纯 CSS 主题开关演示暗/亮两套。
- **状态覆盖**：按需求文档第 7 条，至少覆盖 默认 / hover / disabled（F1、F2 复制）/ 空结果（F2）/ 失败回退（F2 复制失败）/ 模式切换（F4 纯色↔渐变）。
- **收口机会**：F1 撤销/重做、F3 排序等图标按钮，实现时顺手用 `<Button variant="icon">` 收口（对应设计规范 §8 K5）。

## 2. 五功能逐条设计

### F1 撤销 / 重做

- **落点**：`Home.tsx` header 右侧，紧邻「重置」按钮，新增「撤销」「重做」两个图标按钮。
- **控件**：图标按钮 `h-8 w-8`（32px），`Undo2` / `Redo2`，`size={14}` `strokeWidth={2}`。
- **token**：
  - 常态：`text-ink-200 hover:bg-base-700 hover:text-ink-100 rounded`
  - disabled：`opacity-40 cursor-not-allowed`，`title`「无可撤销 / 无可重做」
- **快捷键**：`Ctrl/Cmd+Z` 撤销、`Ctrl/Cmd+Shift+Z`（兼容 `Ctrl+Y`）重做。
- **状态**：历史为空时两按钮均 disabled（见状态矩阵 S1）。

### F2 自定义文件名 + 复制结果

- **落点**：`PreviewPanel.tsx` 结果态下载条（原仅提示 + 下载按钮）。
- **控件**：
  - 文件名输入框：套用文本/数字输入样式（`border border-base-500 bg-base-900/60 px-3 py-1.5 font-mono text-xs text-ink-50 outline-none focus:border-accent-500 focus:shadow-accent-glow`）；默认 `mosaic_${时间戳}`，仅文件名不含扩展名。
  - 下载按钮：保持主按钮（`bg-accent-500 text-base-900`），扩展名按 `result.format` 自动追加。
  - 复制按钮：`Copy` 图标按钮，紧邻下载。
- **状态**：
  - 无 `result`：复制按钮 disabled。
  - 复制成功：`showToast("已复制到剪贴板")`。
  - 复制失败（如 `file://`）：Toast warn 文案「复制失败，请改用下载」，**下载入口保留**（见状态矩阵 S3）。
- **响应式**：下载条 `flex-wrap`，窄屏主按钮不被挤压。

### F3 自动排序

- **落点**：`ImageList.tsx` 头部行右侧按钮组，新增「排序」入口。
- **控件**：`ArrowDownAZ` `size={11}` 图标按钮（与「管理全部」同档）+ 点击展开的下拉浮层（`bg-base-700 border-base-500 shadow-lift rounded`），两项：「按文件名」「按拍摄时间」。
- **下拉项**：`font-mono text-[11px]`，选中态 `bg-base-600` + accent 文字/勾选标记；非模态，点击外部关闭。
- **回退**：无 EXIF 时间时回退「按文件名」并 Toast「部分图片无拍摄时间，已按文件名排序」（排序本身进 F1 历史栈，可撤销）。

### F4 渐变背景

- **落点**：`StitchConfig.tsx`「背景色」组升级为「背景类型」选择。
- **控件**：
  - 顶部 `Segmented`：纯色 / 渐变。
  - 纯色模式：保持现状（取色器 + 文本 + 透明 checkbox）。
  - 渐变模式：两个取色 stop（`from` / `to`）+ 角度 `range`（0–360°，默认 90°）；渐变模式下隐藏/禁用透明 checkbox（渐变以 stop 透明度表达）。
- **token**：Segmented 用 `accent-500` 选中态；角度滑块复用质量 range 定制 thumb（`accent-500` 圆点）；取色器 swatch `rounded` 6px。
- **状态**：纯色↔渐变切换对比见状态矩阵 S4。

### F5 页脚版本 / Commit

- **落点**：`Home.tsx` 整体 `flex h-screen flex-col` 下，`<main>` 之后新增 `footer`。
- **视觉**：`border-t border-base-500`；`font-mono text-[10px] text-ink-200`；左 `v{版本} · {短hash}`，右「本地处理 · 隐私」。
- **约束**：固定高，不抢视觉；暗/亮主题下跟随 token；不引入新颜色。

## 4. 边界与决策

- **离线复制回退（F2）**：`file://` 下 `navigator.clipboard.write` 多数浏览器不支持图片写入。设计稿明确「复制按钮禁用态（无 result）/ 失败回退态（有 result 但写失败）」双路径，下载始终可用——不假设一定能复制。
- **浅色对比（F4/F5）**：accent-500 浅色已加深到 `#00A08C`（设计规范 §1.1），白底主操作达标。注：浅色 accent 对比度 WCAG 数值尚未记录（设计规范 K4），后续改色需补审计。
- **图标按钮收口（K5）**：F1/F3 图标按钮是本稿启用 `<Button variant="icon">` 的天然落点，实现时一并收口，使稿与代码一致。
- **响应式**：仅 F2 下载条需 `flex-wrap`；其余保持桌面优先（设计规范 §4）。
