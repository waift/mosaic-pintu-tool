# MOSAIC 设计规范（Design Spec）

> 本文件是项目**设计令牌（Design Tokens）与 UI 组件视觉规范的权威来源**。
> 架构决策见 `docs/开发报告.md`；功能路线图见 `docs/功能规划.md`。
> 核心原则：**一切视觉取值走 token，禁止散落写死颜色**。

---

## 0. 设计语言（Design Principles）

提炼自实现，作为后续视觉决策的北极星：

- **深色优先的近黑暖灰底**：默认 dark，背景为带暖调的近黑灰（#0E0E12），非纯黑，降低刺眼感。
- **单一强调色（青绿 accent）**：全站只有一个品牌色——青绿（#00E0C6 系），用于主操作、选中、聚焦发光。不引入第二种彩色。
- **克制的警告色（橙红 warn）**：仅用于删除 / 错误 / 失败，出现频率低。
- **工具感与等宽字体**：技术信息（尺寸、状态、百分比、单位）统一等宽字体，强化「本地工具」气质。
- **微交互反馈**：hover 背景位移、focus 发光、选中描边、位移 0.5px 抬升，所有过渡 ≤0.3s。
- **隐私暗示**：空态明示「浏览器本地完成，图片不上传」，呼应本地工具定位。

## 1. 设计令牌（Design Tokens）

所有令牌定义在 `tailwind.config.js`（语义色映射）+ `src/index.css`（`:root` / `.dark` / `.light` 的 CSS 变量）。
颜色变量用 **「R G B 空格分隔」** 格式，以便 Tailwind `<alpha-value>` 支持透明度（如 `bg-accent-500/10`）。

### 1.1 颜色

语义色板分四族：`base`（表面 / 背景层级）、`ink`（文字 / 前景）、`accent`（强调 / 主操作）、`warn`（警告 / 危险）。

#### 合法 Token 白名单（机器可校验）

以下档位为**唯一合法**取值，超出即视为错误，由 `scripts/check-tokens.mjs`（挂在 `npm run lint`）自动拦截：

| 族 | 合法档位 |
|---|---|
| base | 400 / 500 / 600 / 700 / 800 / 900 |
| ink | 50 / 100 / 200 |
| accent | 400 / 500 / 600 / 700 |
| warn | 400 / 500 / 600 |

> 新增档位（如 `accent-300`、`ink-300`）**必须先在此登记 + 在 `tailwind.config.js` 与 `src/index.css` 两处同步定义**；否则编译通过、样式静默失效（幽灵 token）。

### 1.2 字体排印（Typography）

| 角色 | fontFamily | 字体栈 | 用途 |
|---|---|---|---|
| display | `font-display` | "Space Grotesk", "Noto Sans SC", system-ui | 标题、品牌字、按钮主文、区块标题 |
| mono | `font-mono` | "JetBrains Mono", "Sarasa Mono SC", ui-monospace | 尺寸 / 状态 / 百分比 / 单位 / 技术标签 / 数字 |

- 字体经 Google Fonts 在 `index.css` 顶部 `@import` 引入（display / mono 两族）。
- 字号档（实际常用）：display 标题 16px(`text-base`) / 14px(`text-sm`)；mono 信息 8–12px（`text-[8px]` ~ `text-xs`）。
- 区块标题用 `font-display text-xs font-medium uppercase tracking-wider`（如「拼接配置」）。
- 中文混排走 Noto Sans SC / Sarasa Mono SC 回退，无需额外引入。

### 1.3 圆角（Radius）

| Token | 值 | 用途 |
|---|---|---|
| `rounded` (DEFAULT) | 8px | 按钮、卡片、面板、输入、弹窗 |
| `rounded-lg` | 8px | 弹窗 / 模态（与 DEFAULT 同值）|
| 取色器 swatch | 6px | `input[type=color]` 内 swatch |
| `rounded-full` | 9999px | 图标圆形按钮、序号 / 选中徽章、range 滑块 thumb、spinner |

> 统一：容器 / 卡片 / 按钮一律 8px；小控件 / 徽章用圆或全圆。不要出现不规则圆角。

### 1.4 阴影（Shadow）

| Token | 定义 | 用途 |
|---|---|---|
| `shadow-accent-glow` | `0 0 0 1px accent/40, 0 8px 24px -8px accent/35` | 主按钮、选中 Segmented、focus、拖拽态 |
| `shadow-lift` | `0 12px 32px -12px rgba(0,0,0,.6)` | 浮层：Toast、弹窗、img、hover 缩略图 |
| `shadow-inner-line` | `inset 0 0 0 1px ink-50/4` | 内描边（备用，少用）|

### 1.5 动效（Motion）

| Token | 定义 | 用途 |
|---|---|---|
| `animate-fade-in` | `fade-in 0.3s ease-out`（opacity + translateY 4px→0）| Toast、弹窗、lightbox 入场 |
| `animate-spin-slow` | `spin-slow 1.2s linear infinite` | 加载 spinner |
| 过渡惯例 | `transition-colors` / `transition-all`，0.12–0.2s | hover / focus / active；预览平移用 `transform 0.12s ease-out` |

> 约束：入场动效 ≤0.3s；避免触发重排（layout）的属性动画，优先 opacity / transform。

### 1.6 间距（Spacing）

遵循 Tailwind 默认间距尺度（4px 基数）。常用档：

- 面板内边距：`p-3`（列表卡）/ `p-4`（配置面板 / 弹窗内容）
- 工具条：`px-4 py-2` / `py-3`
- 栅格间隙：`gap-1`(4) `gap-2`(8) `gap-3`(12) `gap-4`(16)
- 按钮内距：`px-2.5 py-1.5`（小）/ `px-4 py-3`（主操作）
- 图标按钮：`h-7 w-7` / `h-8 w-8` / `h-9 w-9` / `h-10 w-10`
- 缩略图：`h-20 w-20`（80px）

## 2. 主题系统（Theming）

- 驱动方式：`darkMode: "class"`，`<html>` 挂 `dark` 或 `light` 类。
- 存储：`localStorage["mosaic-theme"]`；初始值解析顺序 = 已存值 → 系统 `prefers-color-scheme` → `dark`（见 `useTheme.ts` 与 `single.html`）。
- **防闪机制（关键）**：`single.html` 在 `<head>` 内联脚本于 React 渲染前同步设置 `html` 的 class 与内联 `background-color` / `color`；`useTheme` 的 effect 再次同步首帧内联色，避免切换主题回闪。
- 全局过渡：`html, body, #root` 含 `transition: background-color / color 0.2s ease`。

## 3. 组件设计模式（Component Patterns）

> 以下 class 组合为「标准写法」，新增组件请直接套用，勿自行发明配色。

### 3.1 按钮（三档）

- **主操作**（生成长图 / 下载 / 批量操作）：
  `bg-accent-500 text-base-900 font-display text-sm font-medium shadow-accent-glow hover:-translate-y-0.5`
  disabled：`bg-base-700 text-ink-200 cursor-not-allowed`
- **次级 / 图标按钮**（主题、重置、管理、清空、缩放、关闭）：
  `text-ink-200 hover:bg-base-700 hover:text-ink-100 rounded`（图标按钮 `h-8 w-8 flex items-center justify-center`）
- **危险操作**（删除选中 / 清空）：
  启用：`bg-warn-500/90 text-white hover:bg-warn-600`
  禁用：`cursor-not-allowed opacity-40`

### 3.2 文本 / 数字输入

`border border-base-500 bg-base-900/60 px-3 py-1.5 font-mono text-xs text-ink-50 outline-none focus:border-accent-500 focus:shadow-accent-glow`

- 数字输入已全局去除箭头；range 滑块 thumb 定制为 `accent-500` 圆点（见 `StitchConfig`）。

### 3.3 Segmented（分段控制）

容器 `flex gap-1 rounded bg-base-900/60 p-1`；选项 `flex-1 rounded px-3 py-1.5 font-mono text-[11px]`，选中 `bg-accent-500 text-base-900 shadow-accent-glow`，未选 `text-ink-200 hover:text-ink-100`。

### 3.4 卡片 / 面板

- 卡片：`border border-base-500 bg-base-700 rounded overflow-hidden hover:shadow-lift`（缩略图卡）
- 面板：`border border-base-500 bg-base-700/40 rounded p-4`（配置区）/ `p-3`（图片列表）

### 3.5 徽章 / 角标

- 序号（左上）：`absolute left-0 top-0 h-4 min-w-4 px-1 font-mono text-[9px] bg-base-900/80 text-ink-100`
- 尺寸标签（底部）：`absolute bottom-0 left-0 bg-base-900/80 px-1 py-px font-mono text-[8px] text-ink-200`
- 多选选中标记（左下）：`h-5 w-5 rounded border border-accent-500 bg-accent-500 text-base-900`（内含 Check 图标）

### 3.6 图标

统一用 `lucide-react`。尺寸档：14（工具条 / 图标按钮）、12（徽章 / 删除）、16 / 18（标题 / 关闭）、20 / 28（空态大图标）；`strokeWidth`：2 或 2.5（强调）/ 1.5（大空态弱）。颜色随邻近文字（`text-ink-200` / `text-accent-400`）。

### 3.7 弹窗 / 模态

- 遮罩：`fixed inset-0 bg-base-900/80 backdrop-blur-sm animate-fade-in`
- 内容：`max-w-3xl rounded-lg border border-base-500 bg-base-700 shadow-lift`（max-h-full + overflow-hidden + flex flex-col）
- 标题栏 `border-b border-base-500 px-4 py-3`；关闭按钮 `h-8 w-8 text-ink-200 hover:bg-base-600`
- lightbox（`ImageModal`）：`z-[60]`，关闭 / 翻页用 `h-9/10 w-9/10 rounded-full bg-base-700/80`

### 3.8 Toast

`fixed bottom-6 left-1/2 -translate-x-1/2`，本体 `bg-base-700/95 border border-base-500 shadow-lift backdrop-blur px-4 py-2.5 font-mono text-[12px] text-ink-50 animate-fade-in`；单条 2.4s 自动消失（store 控制）。

### 3.9 选中 / 拖拽态

- 单选卡 hover：`hover:shadow-lift`；拖拽中 `opacity-50 ring-2 ring-accent-500`
- 多选选中：`border-accent-500 ring-2 ring-accent-500/60`
- **多选整组拖占位（项目特有）**：`opacity-40 border-2 border-dashed border-accent-400/70`（原地虚线镜像，已否决「折叠成 12px 细槽」方案）
- 拖拽浮层（整组）：堆叠卡片 `translate(i*4, i*4) shadow-xl`，主卡 `border-accent-500 ring-2 ring-accent-500/60`

### 3.10 预览四态（PreviewPanel）

| 态 | 视觉 |
|---|---|
| 空态 | 空图标圆 `bg-base-700/50` + display 标题 + mono 步骤 + 隐私提示 |
| 生成中 | `animate-spin-slow` 环 + mono 文字 |
| 错误 | warn 图标圆 `bg-warn-500/10 text-warn-500` + warn 文字 + mono 错误信息 |
| 结果 | 工具条（尺寸·格式·KB·% + 缩放 / 自适应）+ **透明棋盘格画布**（24px，滚轮缩放 / 拖拽平移 / 默认自适应 92% 边距）+ 下载条 |

- 透明棋盘格：双向 `linear-gradient` 45° / -45°，用 `ink-50/0.04`，`background-size: 24px`，跟随主题。
- 全局噪声纹理：`body::before` 固定层 `opacity: 0.04` 的 fractalNoise SVG，营造质感（`#root` z-index 1 在其上）。

## 4. 布局与响应式（Layout）

- 整体 `flex h-screen flex-col`；header `border-b px-6 py-3`。
- 左控制栏 `aside`：`w-2/5 min-w-[360px] max-w-[480px] flex-col gap-4 overflow-y-auto border-r p-4`。
- 右预览 `section`：`flex-1 overflow-hidden`。
- 弹窗 / Toast 挂在根层。
- 当前为**桌面优先**工具（依赖拖拽 / 粘贴）；`ImageManagerModal` 用 `md:p-8`（小屏 `p-4`）做最小响应式，未做完整移动适配。

---

## 5. 文案与语言风格（Voice）

- 界面以**中文**为主；技术量值（尺寸 `1920×1080`、百分比、`KB`、单位 `px`、快捷键 `Ctrl+V`）一律 `font-mono`。
- 标题 / 品牌用 display；状态 / 提示用 mono 小字。
- 表述直接、工具化，如「单击就绪 · 双击上传 · 拖拽放入」「按 Ctrl+V 粘贴图片」「拖到此处 → 放到末尾」。
- 所有可操作元素配 `title` 提示（hover 工具提示 + 可访问性）。

---

## 6. 交互与可访问性（A11y / Interaction）

- 所有交互元素具备 `title`；危险 / 禁用操作可视化（opacity + cursor-not-allowed）。
- 键盘：Esc 关闭弹窗 / 预览；← → 切换大图；全局 `Ctrl+V` 粘贴图片。
- 拖拽用 `@dnd-kit` 的 `PointerSensor`，`activationConstraint: { distance: 5 }` 区分点击与拖拽。
- 滚动条细定制（8px，thumb 用 base-500）。
- 弹窗打开时 `document.body.style.overflow = "hidden"` 锁滚动，卸载还原。

## 7. 反模式（Do NOT）

1. ❌ 在组件里写死十六进制 / 具体 rgb（主题与棋盘格实现必需除外）。✅ 一律 token + alpha 变体。
2. ❌ 新增大段组件级 CSS（如新建 `.my-btn`）。✅ 优先 Tailwind utility + 已定义 token；确需全局样式放进 `index.css`。
3. ❌ 引入第二种品牌彩色。✅ 全站仅 accent（青绿）+ warn（橙红）。
4. ❌ 浅色下沿用深色 accent-500（#00E0C6）做白底主操作。✅ 浅色已加深到 #00A08C，新增强调场景保持对比度。
5. ❌ 新增颜色 / 状态档只改 `tailwind.config.js` 或只改 `index.css` 一处。✅ 两处同步（config 映射 + CSS 变量）。
6. ❌ 入场动效 >0.3s 或动画 layout 属性。✅ 仅 opacity / transform，≤0.3s。
7. ❌ 用 BrowserRouter。✅ 保持 `HashRouter`（GitHub Pages 子路径兼容，详见 README）。
