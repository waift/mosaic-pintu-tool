## 多选拖拽修复：原地镜像 + 放到末尾（fix → 待 commit/push main）
- 用户反馈两个遗留问题：
  1. 多选拖动时原地镜像差——被拖动那张原地没有镜像图
  2. 多张拖动无法放到队列最后
- 根因定位（Playwright 实测 + 碰撞检测日志）：
  - **放不到最后**：原方案用 `useDroppable({id:"__DROP_END__"})` 哨兵 droppable，但实测 `droppableContainers` 列表里根本没有任何 `__DROP_END__`（endRect=undefined）——该哨兵 droppable 从未注册成功，`pointerWithin` 永远只返回图片 id，`over` 从不变成 `__DROP_END__`。
  - **原地镜像**：被拖项其实已有 opacity-40 但太弱（无边框），用户感知为"图没了"。
- 修复（改 ImageManagerModal.tsx，已清掉所有 DBG/COLLIDE 调试 log）：
  1. **放末尾**改为指针坐标判定：onDragEnd 用 `activatorEvent.clientY + delta.y` 得到指针最终 Y，与 `endZoneRef`（末尾虚线投放区 DOM 引用）的 `getBoundingClientRect().top` 比较，`pointerY >= top-6` 即视为放到末尾。不再依赖不可靠的哨兵 droppable。
  2. **原地镜像**：整组拖动中选中项统一加 `border-2 border-dashed border-accent-400/70` + `opacity-40`，被拖那张也含（原地清晰留虚线占位框）。
- Playwright 实测验证（dev 5173 + 系统 Chrome channel）：
  - ✅ GHOST_IN_PLACE：选中 3 张(含 active)均 dash=true op=0.4
  - ✅ 整组拖到末尾：[img1,5,6, 选中组] ✓；单张拖到末尾 img1→最后 ✓；整组拖到最前 [选中组,img1,5,6] ✓（普通重排完好）
  - ✅ tsc -b --noEmit 零报错；无 pageerror
- 注意：本环境 Edit 工具不稳定，本文件用 Write 全量重写完成。
